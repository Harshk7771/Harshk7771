## 🕸️ Flagship Project: Project Chakravyuh

**चक्रव्यूह — Next-Generation Autonomous SOC Platform**

An enterprise-grade, fully open-source SOC platform delivering defense-in-depth through six concentric layers of detection, correlation, and response — unifying SIEM, EDR, SOAR, Threat Intel, and Digital Forensics into a single platform. Designed with Indian defence, LEA, and enterprise security operations in mind.

<div align="center">

| 100% | 14+ | &lt;2s | 10M+ | 25+ |
|:---:|:---:|:---:|:---:|:---:|
| Open Source | Integrated Modules | Alert Triage Time | Malware Signatures | Configurable Tools |

</div>

**🎯 Layered Architecture (Defense in Depth)**

| Layer | Function | Stack |
|---|---|---|
| **01 · Outer Perimeter** | Network monitoring, deep packet inspection, anomaly detection | Suricata, Zeek, NetFlow, PCAP |
| **02 · Endpoint** | EDR — behavioral analysis, memory scanning, automated containment | Wazuh, Velociraptor, YARA, eBPF |
| **03 · Intelligence** | SIEM — log correlation, ML-based scoring, MITRE ATT&CK mapping | OpenSearch, Sigma Rules, ML Engine |
| **04 · Threat Intel** | Multi-source feeds, IOC enrichment, actor tracking | MISP, VirusTotal, OpenCTI |
| **05 · Response** | SOAR — playbook automation, CVSS-based case assignment | n8n, TheHive, Cortex |
| **06 · Forensics** | Evidence acquisition, chain-of-custody, timeline reconstruction | Volatility 3, Autopsy, DFIR-IRIS |

**🧩 Additional Capabilities**
- AI-based alert triage & case management with SLA tracking
- SpiderFoot OSINT chaining across 200+ data sources
- Five-layer IP reputation stack (AbuseIPDB, Shodan, IPinfo.io, CIRCL, GreyNoise)
- Automated static/dynamic file analysis (YARA, oletools, CAPE Sandbox)
- Phishing/mail forensics pipeline (PhishTank, MXToolbox, header analysis)
- Hayabusa Windows Event Log hunting + Timesketch DFIR timelines
- Plugin architecture — every integration toggled via `registry.json`, no code changes
